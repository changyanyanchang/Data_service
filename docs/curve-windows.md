# 曲线窗口存储 v1

`readCurveSlice` 的深度窗、`readCurveWindow` 的样点索引窗和 `readTable("curves")`
共用窗口读口。不重采样、不排序、不换单位；重复/乱序深度保留原样，深度过滤含端点。
按样点取数保留缺失深度；有深度范围时排除非有限深度。

新导入在同一个来源事务中同时写入兼容 BLOB 与版本化 `curve_window_*_v1` 小块表。
每块至多 4096 个样点。深度/TVD/TVDSS 轴按曲线组共享，曲线 raw/processed/quality
独立分块；double 使用既有 float64-le 编码，处理值 SQL NULL 表示回退原始值。
原始值、来源空值质量标记、有效负数和深度声明不修改。

深度查询先按块的有限深度 min/max 选候选，再读取小块并逐点精确筛选。该索引不假定
轴单调；交错/乱序轴可能命中较多块，实际读取仍受总字节/样点预算限制。索引窗按块
主键查询，晚页不会先解包前面的曲线数据。范围索引并不承诺任意非单调轴都有常数成本。

`CurveReadOptions` 控制交付样点、累计数值载荷字节和取消；输出失败/取消时清空。
`CurveReadStats` 报告从 SQL 返回的数值/质量 BLOB 载荷字节、小块数及旧载荷物化量，
不把它冒充实际磁盘、页缓存、进程 RSS 或 SQL 元数据读取计数。长度预检不取回旧数值 BLOB。
预算包括读取支撑块而非只计算最终交付样点；带辅助轴的索引窗也计入相关字节。

旧库只读打开不会建表或升级。没有有效小块的旧曲线在全部需要物化的 BLOB 同时满足
`maxLegacyBytes`（默认 1 MiB）和总读取预算时，才走有限兼容读取。即便只请求一个点，
统计也会记录整份旧载荷。超过预算返回 `CurveWindowMigrationRequired`，不使用
`substr(BLOB)` 返回量冒充 SQLite 内部没有物化完整 BLOB 的证明。

`upgradeCurveWindowStorage` 是显式写事务，累计旧载荷默认上限 64 MiB，逐组共享轴，
可取消；预算不足、取消、坏长度或失败整体回滚。它是有限规模的兼容迁移，不提供大 BLOB
增量迁移，也不接入另一份 SQLite native handle。大旧载荷需要后续有界迁移工具。
迁移只增加小块表示，保留对象 ID、兼容 BLOB 和原始数值。完整迁移后重复执行不读旧载荷。

SDK 清理/编辑在原有写事务中同步小块，失败一并回滚。兼容 SQL 对旧数组的修改由触发器
使相应小块失效，读取不交付旧值；之后受有限兼容/显式迁移规则约束。当前仍保留完整 BLOB
和完整 `readLogSet` 契约，编辑与重清理仍有整条读写及双表示存储放大；本批没有实现历史
不可变数值块、低写放大编辑、数值载荷的完整变更历史或按版本恢复旧数值；薄元数据日志见 model-changes.md。
