# I2 前置：认证字节上的精确地震窗口

日期：2026-11-15；依赖数值表投影 PR #22，执行/测试冻结 `5c40bbc1`。
接口和支持范围见 [契约](../authenticated-seismic-window.md)；主仓 I2 负责真实文件认证、
受控 Python 和成果链路，本 SDK 验证不代替主仓验收。

新增标准 C++ `SeismicWindowReadCut`、描述/查询/预算/结果 DTO 和可信宿主范围回调。
描述只读有界元数据，读取校验实际模型切面及独立完整源 SHA，经同一认证回调读取
二进制头、所选道头与样点；不打开源路径、不隐式迁移、不加载整卷数组。
首版限定固定长度、big-endian IEEE32、SEG-Y rev1，明确的 ms、TWT/OWT、时间参考和
振幅单位，每窗至多 8192 点。未知或不支持的约定明确拒绝，不推断、转换或插值。

SDK 保留注册源指纹，但 `quick:` 只作元数据；独立完整 SHA 来自可信宿主，不能将
快速指纹升级为认证。SQL 字节守卫先于文本物化；严格 UTF-8、元数据修订、窗口和
预算先于样点读取。非有限源振幅使用显式 null mask 与零占位；负值和有效零保留。
认证失败、短读、异常、漂移或取消均不交付部分数组。

实际 Linux 独立构建包含新 `seismic_window_tests` 与受影响回归目标；最终 CTest
**11/11，48.92 秒**。新测试由临时真实 SDK 库及完整散列的不可变内存 SEG-Y 构造，
覆盖数值/实际道键/窗口轴、源路径不可用但回调仍可读、模型修订、完整/快速指纹边界、
载荷前预算拒绝、NaN/null、错误格式、回调异常、取消和过大元数据。
这些内存回调测试验证 SDK 的嵌入契约，不声称实现文件系统认证或进程隔离。
