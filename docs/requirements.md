# 开发范围与约束

本仓库提供独立的数据服务原型，用公开 C++ 接口连接文件、持久化数据与后续业务模块。公开结构体和方法以 `include/paleo_data` 为准。

## 数据与功能

- 单井资料包含井基础属性、深度约定、曲线组、分层道、样品表、测斜、时深关系、岩心照片和附件。
- 已由宿主声明 comprehensiveWellMetreDepth 的综合工作簿，MD 顶深/底深列可由道名、层号及 TVD 列隔开。
  旧库存分层道未保存声明时，读口继承该来源的显式 MD/m 契约；显式道约定优先，原始元数据和深度值不改，离线及只读同样有效。未声明的普通来源保持未知。
- 曲线组同样继承已确认综合工作簿的缺失 MD/m 字段，显式 TVD/英尺不覆盖。LAS 解析接受
  MD/DEPT/DEPTH 测深索引并保留其实际单位；旧 LAS 组的缺失 MD 标记在只读读口恢复，
  不补猜缺失单位，不改写原始轴或库存元数据，不依赖原始文件仍在线。
- 工区级地震资料包含地震体、层位和剖面路径；层位/剖面可关联所属地震体。
- 地质平面图保存图名、类型、工区、地层、文件路径和配准状态；普通图片不自动变成空间多边形。
- 解析保留原始值、工作表位置、来源信息和待核对项。读取/保存接口使用稳定编号。
- SQLite 管理结构化对象和来源元信息。大型地震体不复制进工区，也不将全体振幅存入数据库。
- 界面提供创建/打开工区、导入、核对、修改、查询、预览及接口代码演示。

## 实现约束

1. C++20、CMake，Qt6 作为内部依赖。公开对象优先使用 `std::string`、`std::vector`、整数和浮点数。
2. 解析层不访问 SQL/UI；业务层通过数据流转层获取对象。界面只调用公开服务。
3. 每个文件独立事务。取消时不发布未完成结果，已完成文件保留。重复导入不能覆盖人工修改。
4. 原始值与处理值分开；空值、异常和手工修改有可读的质量标记。负数合法性取决于曲线及约定。
5. 坐标、深度基准、单位和时间类型有歧义时明确提示，不自动推断或仅改单位标签。
6. 多线程只准备文件；协调线程按排序保存结果，避免并发完成顺序影响归井与冲突处理。
7. 数据完整性、取消、来源变化、重开、编辑和线程一致性使用合成测试验证。

来源重定位提供只读准备 / 所属线程提交两段接口。`readSourceIndexEntry` 按主键
查单一来源，不能先枚举所有来源。`prepareSourceRelocation` 按记录的指纹类型
核验候选（SEG-Y quick 最多 64 KiB，普通 SHA-256 可取消分块读取），返回绑定工区、
来源行和候选元数据的不可变结果。`commitSourceRelocation` 只更新数据库元数据，
不重复读取源内容；来源行、工区或候选元数据变化时拒绝提交。原始路径声明和外部
文件内容保持不变；后缀改名不改变已有指纹算法。quick 只表示快速身份匹配，
不构成全文件完整性校验。宿主负责自己的目录版本登记与跨库恢复。

## 当前边界

### 同一地层单元的多次井出现

分离、无重叠的实际井出现分别保存，提交时分配 `occurrenceId`，后续修订中的显式编辑保留该身份。
不把身份移到另一井或父单元；旧不可变修订不回写。跨轴、缺少单位/完整范围或重复重叠的多次出现拒绝提交。
`wellRangeForOccurrence` 按井、子层段及精确出现身份解析各自的实际深度；不提供出现选择的 `wellRange`
与旧内部边界编辑入口在有多次出现时明确拒绝，不取第一条或合成 MIN/MAX 范围。已知 m/ft 仅用于同轴比较，
返回值仍保留实际出现的原轴与单位。结果值指纹覆盖每次出现，第二次出现的几何改变同样触发失效。

### 有界井查询元数据

`readWellQueryValue` 按稳定井 ID（或明确的精确井名）点读 ID、原始井名和总井深，
不加载曲线、备注或逐井统计；缺失行用 `found=false` 区分 I/O 失败。总井深保留
原值和 NaN，不推断单位。井名输入及输出限制 4096 UTF-8 字节，超限拒绝而不截断。
`findWellIdsByQueryName` 使用 Unicode 字符小写并忽略空白、连字符、下划线的派生索引，
按 `(name_key,well_id)` 游标取 1–256 个 ID。可写开库的事务建立/修复此索引，井变更
与变更日志在同一事务维护；旧写者留下 dirty 标记时只读查询明确拒绝，不能全表读取
后截成小页，也不在只读会话迁移库。调用方负责绑定模型 store/generation/head，
以及将 SDK 身份映射到自己的有效井集合。

### 文档来源与多体系查询补强（2026-11-05）

- 已准备的来源重定位通过 `openProjectForSourceRelocation` 打开所属库，仅执行格式检查与
  按主键路径提交；不运行普通开库的全井坐标归一。只读实例不能直接升级，跨工程、
  未来格式、来源行变化或候选文件变化均拒绝提交。宿主可用只读 `snapshotDatabase`
  创建新模型，再重定位新快照，保留旧数据库；可取消快照与部署要求见下文。
- 地震分层构建的方案提交和道物化同处一个事务。生成道携带生成者、方案和修订，
  不删除用户同名道或其他方案/历史修订产物；同修订重复物化保持幂等。
- 井曲线层段查询遵从显式来源、方案修订、道/记录 ID。固定引用失效不回退当前头，
  同名歧义保持未解决；未知轴/单位不补成 MD/m，不跨轴、单位或已知起算面切片。
  曲线值、每井重采样、辅助区间均有预算和取消检查；非有限数、不能推进的步长、
  超预算或取消明确失败并清空输出。
- 窗口深度换算使用请求中的逐井时深绑定，未给出时只读已保存的逐井优选，
  不选第一条关系。关系必须属于该井且有效，明确 MD、单位、起算面、时间零点、
  OWT/TWT、时间单位以及与目标体一致的平面约定；不猜秒、不取绝对值、不外推。
  返回深度状态、警告和实际所用关系；未能换算时保留 NaN，振幅仍可独立读取。
  深度计算另有工作预算，不静默减少参与空间插值的关系。
- `timeSign` 随原始导入保存，读取时仅按明确 `negated` 元数据统一符号一次；
  解释快照保存已交付数值及符号依据，重开时不再次取反。

### 对象修订、用途与成果失效（第二阶段）

`describeDataObject` 按类型和实际 ID 返回时深、分层道、地震体的所属来源/井及修订，
不解析数值数组。附加修订表和触发器跟踪语义及数据改变，显示名与纯文件定位不改变
修订；删除后重用 ID 也不能复用旧令牌。只读旧库明确返回修订未知，不自动写库；
`upgradeObjectRevisionSchema` 显式事务升级，可在提交前取消。修订是变更令牌，
不承诺恢复旧数值。`readTimeDepthAtRevision` 在单一只读事务内校验令牌并读取
指定对象，限制 JSON 字节/点数，失败或取消不交付半份表。

成果几何指纹按消费类型比较：井相使用实际井的 MD 范围，地震相使用实际层位资源
与子层段顶底比例。无关井、仅地震分界的变化不误伤未消费它们的结果；修改层位资源
身份必须使对应地震成果失效。旧通用指纹继续兼容。宿主负责将待复核状态投影到目录，
及维护时深选择/语义的实际消费依赖，SDK 不猜调用方是否使用了时深。

### 可取消数据库快照

`snapshotDatabaseCancellable` 启动随应用部署的 `paleo_data_snapshot_worker`，只读
源库，用当前 Qt SQL 驱动执行快照。父进程在 25ms 轮询点检查取消及超时，终止后
清理私有暂存，成功校验后才发布不覆盖的目标。旧 `snapshotDatabase` 使用五分钟
默认超时。快照包含已提交 WAL，保持对象 ID/BLOB，不复制未提交修改，原库不变。
操作系统终止失败时不发布目标并保留私有暂存目录，不承诺此极端情形已清理。

组件是运行依赖，即使 `PDS_BUILD_TOOLS=OFF` 也会构建，安装到 bin。
部署到主程序同目录或 `../libexec/`，同时提供当前应用的 Qt Core/Sql 和 SQLite
插件；绝不从系统 PATH 选择辅助程序。缺失、崩溃、超时、取消或无效输出均失败。
完整快照仍消耗与库大小相关的时间和磁盘空间，不能视为常数成本。

工作簿公式读取缓存结果，不在导入时重算。部分专有格式、媒体和压缩包仅登记。未提供通用 OCR 或自动地质推理模型。

SEG-Y 支持情况见 [地震指南](segyio-guide.md)。多线程调度预算是估算值，不是进程内存硬上限；缓存变化检查也不等同于完整内容审计，见 [导入指南](import-performance.md)。

源码发布不携带任何数据文件或私人验收材料。测试和演示输入由生成器在临时目录或用户选定的外部目录创建；生成结果应保持在版本控制之外。

## 层段预测与单因素取数

`readSeismicHorizonWindow` 使用与剖面叠加相同的索引化层位采样器，按明确的地震体、
方案修订和子层段读取振幅。不得以层位全表扫描、时间绝对值或域外最近邻填补缺测。
调用方可显式提供未声明的时间单位/类型；已有声明优先，冲突拒绝读取。时间符号保持
原样，单位和 OWT/TWT 只按明确约定换算。

S1–S3 的原生样点及归一化取样含顶不含底，S4 包含底界；固定长度重采样可读取窗口
两侧各一条支撑样点做线性插值，但原生样点计数与振幅统计只统计实际层段内样点。
井曲线层段查询采用同一边界规则。结果携带实际方案修订与有效状态。

窗口查询在一个只读快照内完成，取消或失败清空输出，不留下半份结果。总道数上限
65536、每道重采样上限4096，振幅值总量另受查询预算限制；大型 SEG-Y 保持外部只读。

## 井震时间口径配对

`confirmTimeDepthAlignment` 接受明确的时深条目集合，按所属来源批量保存
ms/s、TWT/OWT、时间基准及符号声明，可在同一事务中为一个 TWT 地震体登记
共同时间零点。地震体既有采样单位须已明确为 ms/s；已声明 OWT 的体不能直接
重标为 TWT。失败不留下部分来源或地震基准。原始时深点及地震采样轴、振幅不改，
重复保存不重复取反。时间基准不能从默认平面坐标系继承。

## 工区平面坐标约定

新建工区默认 EPSG:32650（WGS 84 / UTM 50N）、米；已有明确的导入或人工选择优先。井、地震体、层位和剖面读取时共用工区约定，仅补足未声明项。已有明确 CRS/单位不覆盖，不重投影、不换算 XY，不修改外部 SEG-Y 或原始来源声明。范围接口使用同一有效约定，声明冲突仍拒绝合并。此默认不适用于深度、时间基准及时间符号。

## 剖面层位叠加读口

同时返回方案明确关联的层段顶底曲线 ID，以及 S1–S4 的邻接关系和名称，
供剖面生成层间色带。没有方案关联不按时间排序猜层段，缺失的界线不跨接。

`readSectionHorizons` 按调用方提供的实际显示道序（含缺道、重复道及任意线折返）
返回大层界面与方案修订中的 S1/S2、S2/S3、S3/S4 分界，单位为 TWT 毫秒。
只查结构化层位元数据，不读地震振幅、不用井时深、不写工区或外部文件。
方案关联资源和分界比例是小层几何权威，初始推导与确认分界保留状态。

优先使用原始点；缺测道、显式空值、顶底倒置与覆盖域外均保留 NaN 断线。
仅在指定测线邻域内、上下行均在交线两侧有支撑点时插值；默认半径 64，最大 128。
按测线索引查询有界窗口，先在各行内插值、再在行间插值；两行可有不同的交线采样，
无需四角交线编号相同。查询点始终位于两行各自的覆盖内，不外推、不做最近点补齐。
相邻网格行、列的跨度也不得超过邻域半径，避免超限网格只在中心生成孤立插值条带。
网格行必须在查询交线附近包围该交线；远处仅有少量拾取点的同名测线行不得遮蔽
井旁完整网格。选择行时保留空值点的几何位置，不能跳过显式空值去借更远的行。
保留时间原始符号，明确的 s/ms、OWT/TWT 约定按数值换算；缺声明时必须由
调用方显式给出显示约定，声明冲突的层位跳过并返回原因。读取在单一只读快照内，
返回实际方案修订，取消或失败清空结果。列数上限 65536、总界线点数预算 800 万。
点查询固定使用既有 `horizon_line` 索引，避免 ORDER BY / LIMIT 选择序号索引后
逐道扫描整个层位；不对每个层位执行库存点数统计。

相邻查询复用采样器内的局部测线块，任意线为 64×64；纵横测线分别为 1×512、
512×1，四周仅增加当前插值半径的支撑。每个 inline 使用等值索引匹配，
确保 `(horizon_id,inline_no,crossline_no)` 索引同时约束两维，避免反复扫描整行。
每块最多读取 131072 个源点；超限回退原有逐点索引查询，不截断后冒充有效网格。
分块只改变 SQL 调度，不改变原始点/显式空值/重复点 seq、id 优先级和两级插值结果。
缓存属于当前只读快照，不跨事务复用。剖面叠加与层段取窗共用这一采样器。
