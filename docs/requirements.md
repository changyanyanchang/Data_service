# 开发范围与约束

本仓库提供独立的数据服务原型，用公开 C++ 接口连接文件、持久化数据与后续业务模块。公开结构体和方法以 `include/paleo_data` 为准。

## 数据与功能

- 单井资料包含井基础属性、深度约定、曲线组、分层道、样品表、测斜、时深关系、岩心照片和附件。
- 工区级地震资料包含地震体、层位和剖面路径；层位/剖面可关联所属地震体。
- 地质平面图保存图名、类型、工区、地层、文件路径和配准状态；普通图片不自动变成空间多边形。
- 解析保留原始值、工作表位置、来源信息和待核对项。读取/保存接口使用稳定编号。
- SQLite 管理结构化对象和来源元信息。大型地震体不复制进工区，也不将全体振幅存入数据库。
- 界面提供创建/打开工区、导入、核对、修改、查询、预览及接口代码演示。

## 实现约束

1. C++20、CMake，Qt6 作为内部依赖。公开对象优先使用 `std::string`、`std::vector`、整数和浮点数。
2. 解析层不访问 SQL/UI；业务层通过数据流转层获取对象。界面只调用公开服务。
3. 每个文件独立事务。取消时不发布未完成结果，已完成文件保留。重复导入不能覆盖人工修改。
4. 原始值与处理值分开；空值、异常和手工修改有可读的质量标记。负数合法性取决于曲线及约定。
5. 坐标、深度基准、单位和时间类型有歧义时明确提示，不自动推断或仅改单位标签。
6. 多线程只准备文件；协调线程按排序保存结果，避免并发完成顺序影响归井与冲突处理。
7. 数据完整性、取消、来源变化、重开、编辑和线程一致性使用合成测试验证。

## 当前边界

工作簿公式读取缓存结果，不在导入时重算。部分专有格式、媒体和压缩包仅登记。未提供通用 OCR 或自动地质推理模型。

SEG-Y 支持情况见 [地震指南](segyio-guide.md)。多线程调度预算是估算值，不是进程内存硬上限；缓存变化检查也不等同于完整内容审计，见 [导入指南](import-performance.md)。

源码发布不携带任何数据文件或私人验收材料。测试和演示输入由生成器在临时目录或用户选定的外部目录创建；生成结果应保持在版本控制之外。

## 工区平面坐标约定

新建工区默认 EPSG:32650（WGS 84 / UTM 50N）、米；已有明确的导入或人工选择优先。井、地震体、层位和剖面读取时共用工区约定，仅补足未声明项。已有明确 CRS/单位不覆盖，不重投影、不换算 XY，不修改外部 SEG-Y 或原始来源声明。范围接口使用同一有效约定，声明冲突仍拒绝合并。此默认不适用于深度、时间基准及时间符号。
